# Ingrid Itzel Rosas Cabello - Portafolio

Landing CV personal de Ingrid Rosas, Diseñadora Gráfica Digital. Proyecto de la materia de Tecnologías Emergentes de la Universidad La Salle, Ciudad de México.

El repositorio contiene el sitio web de portafolio profesional con secciones de presentación, educación, intereses, habilidades, herramientas, portafolio de trabajo y contacto. Incluye modo oscuro, animaciones de scroll reveal, carruseles automáticos, lightbox para vista amplia de proyectos y diseño responsivo.
